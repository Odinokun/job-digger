# src/server/settings - налаштування користувача

Особисті налаштування, що живуть у базі (таблиця `settings`, задача 6.01). Зараз це
лише інтервал автоматичної перевірки. Тема й мова - у cookie, не тут: чому -
[`lib/theme.ts`](../../lib/theme.ts).

| Файл                            | Що в ньому                                                    |
| ------------------------------- | ------------------------------------------------------------- |
| `settings.ts`                   | `getSettings` і `setAutoCheckInterval`                        |
| `settings.integration.test.ts`  | значення за замовчуванням, перезапис, ізоляція користувачів, `CHECK` у базі |

- **Рядок зʼявляється з першим вибором.** Доки його немає, `getSettings` віддає
  значення за замовчуванням (`DEFAULT_AUTO_CHECK_INTERVAL`, 6 год). Тому ні seed,
  ні створення користувача про налаштування знати не мусять.
- **Запис - один `insert ... on conflict do update`**: і перший вибір, і зміна
  проходять одним запитом, без «прочитати, тоді вирішити».
- **Перелік інтервалів** живе в
  [`lib/settings/auto-check-interval.ts`](../../lib/settings/auto-check-interval.ts):
  з нього і список на сторінці, і `CHECK` на колонці. Значення з клієнта
  проходить `parseAutoCheckInterval`, і хибне відхиляється, а не підміняється.
