# src/server - серверна частина

Тут живе весь серверний код застосунку, окремо від сторінок і компонентів у
[`src/app`](../app) ([розділ 14](../../docs/process.md), «Репозиторій»).

Що тут буде:

- **Server Actions** - усі зміни даних проходять через них ([розділ 13](../../docs/security.md), пункт 2).
- **Робота з БД** - схема Drizzle, міграції, запити ([розділ 9](../../docs/data.md)).
- **Черга завдань** - захоплення завдань, повернення завислих, прогрес ([розділ 8](../../docs/checks-and-queue.md)).
- **Парсери** - ATS і schema.org JobPosting ([розділ 6](../../docs/discovery-and-parsing.md)).
- **Модуль HTTP-запитів** - ввічливість до сайтів і захист від SSRF ([розділи 6 і 13](../../docs/security.md)).

Правило: модулі з `src/server` не імпортуються в клієнтські компоненти напряму.
Клієнт звертається до сервера лише через Server Actions або серверні компоненти.

Готові підпапки:

- [`db`](db/README.md) - схема, підключення до PostgreSQL, міграції й seed.
- [`companies`](companies/README.md) - очищення адрес компаній і пошук дублікатів.

Решта (`queue`, `parsers`, `http`) створюються у своїх задачах, а не наперед.
