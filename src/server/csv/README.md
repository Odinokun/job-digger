## Формат

Чотири колонки: `company_name`, `company_url`, `career_url`, `career_label`. План
давав три; `career_label` додано рішенням автора 20.11.2026 - без неї підписи
джерел («USA», «DE» у Mozilla) губилися б при перенесенні Export → Import.

- Один рядок - одне джерело; компанія без джерел - один рядок із порожніми
  `career_url` і `career_label`.
- Файл починається з BOM, рядки закінчуються CRLF (RFC 4180).
- **Формули.** Поле, що починається з символу, з якого таблиця може почати
  формулу, отримує одинарну лапку спереду й береться в лапки. Список символів -
  з OWASP «CSV Injection» і ширший за docs/security.md: окрім `=`, `+`, `-`, `@` -
  Tab, CR, LF і повноширинні `＝＋－＠`. OWASP попереджає, що Excel може зняти
  екранування після збереження й повторного відкриття файлу, і універсального
  захисту немає. Імпорт знімає лапку, якщо за нею йде такий символ.

## Import

Розбір - `parse.ts`, запис - `import.ts`. Рішення (задача 6.06):

- **Файл відхиляється цілком** лише за заголовком: невідома чи повторена колонка
  або немає обовʼязкової. Колонки шукаються за назвою, порядок довільний; файл без
  `career_label` (старий триколонковий) приймається. Розділювач - `,` або `;`, за
  заголовком. BOM необовʼязковий.
- **Лапка формули** (`'` перед `=`, `+`, … - так пише експорт) знімається; інша
  лапка на початку - частина значення.
- **Та сама компанія** - точний збіг очищеної адреси сайту; компанія без сайту - за
  своєю карʼєрною сторінкою. Попередження «той самий домен» і «та сама назва» в
  імпорті не зупиняють: підтвердити їх нікому. Назва наявної компанії не міняється.
- **Підсумок:** додані компанії й сторінки; дублікати - кожна сторінка, яка вже є
  в цієї чи іншої компанії, і рядок без сторінки для компанії, що вже є (зокрема
  повтори всередині файлу); помилки - рядок без назви, без обох адрес, із кривою
  адресою або з іншою кількістю полів.
- Рецепт власної сторінки (задача 6.21) і позначка «Link only» (6.17) у файл не
  потрапляють: після Import така сторінка знову Unsupported, рецепт дається кнопкою
  Read as list заново.
- Усе однією транзакцією. Пошук сторінок після імпорту не запускається; компанія
  без сторінок - у Not tracked зі статусом Not checked.
