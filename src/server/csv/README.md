# src/server/csv - CSV компаній

Export і Import зі сторінки Settings (docs/ui.md, розділ 10; задачі 6.05-6.07).

| Файл             | Що в ньому                                                   |
| ---------------- | ------------------------------------------------------------ |
| `format.ts`      | `CSV_COLUMNS`, `escapeCsvCell`, `toCsv` - формат файлу        |
| `format.test.ts` | Лапки за RFC 4180, екранування формул, BOM і CRLF            |

## Формат

Чотири колонки: `company_name`, `company_url`, `career_url`, `career_label`. План
давав три; `career_label` додано рішенням автора 20.11.2026 - без неї підписи
джерел («USA», «DE» у Mozilla) губилися б при перенесенні Export → Import.

- Один рядок - одне джерело; компанія без джерел - один рядок із порожніми
  `career_url` і `career_label`.
- Файл починається з BOM, рядки закінчуються CRLF (RFC 4180).
- **Формули.** Поле, що починається з символу, з якого таблиця може почати
  формулу, отримує одинарну лапку спереду й береться в лапки. Список символів -
  з OWASP «CSV Injection» і ширший за docs/security.md: окрім `=`, `+`, `-`, `@` -
  Tab, CR, LF і повноширинні `＝＋－＠`. OWASP попереджає, що Excel може зняти
  екранування після збереження й повторного відкриття файлу, і універсального
  захисту немає. Імпорт знімає лапку, якщо за нею йде такий символ.
