# 6.24 Платформа Jobico

**Етап 6 — Автоматизація та Settings** · строго TDD для парсера

## Що перевірено 20.11.2026

- Сторінка компанії (`jobico.io/en/jobs?company=usoftware`) зібрана JavaScript-ом, вакансій у HTML немає.
- Офіційна стрічка `jobico.io/api/feeds/jobs.xml` - усі вакансії сайту (334, ~300 КБ); `robots.txt` прямо її дозволяє (`Allow: /api/feeds/`). Поля: `id`, `link`, `title`, `company`, `country`, `city`…
- Сайту компанії в стрічці немає.

## Рішення автора 20.11.2026

- Платформа: адреса сторінки компанії на Jobico → вакансії зі стрічки за полем `<company>`.
- Find pages шукає за назвою компанії у стрічці; знахідка без підтвердження - з позначкою «перевір».
- Платформа в правилі дублікатів 6.20.

**Перший крок - правила користування Jobico.** Якщо забороняють автоматичне читання - задача закривається без коду.

На старті: як зіставляти компанію (назва в стрічці проти параметра `company` в адресі); чи читати стрічку раз на перевірку для всіх джерел Jobico.

## Закрито без коду (20.11.2026)

Правила Jobico ([jobico.io/terms](https://www.jobico.io/terms)): «Забороняється використовувати автоматичне парсування, ботів або інші інструменти для витягування даних». XML-стрічка з `robots.txt`, судячи з правил, - для партнерських агрегаторів, яким Jobico сам передає вакансії. **Рішення автора:** закрити без коду - у автора там одна компанія з однією вакансією.
