# Підготувати репозиторій до показу

**Поза етапами — документація** · без тестів, ручна перевірка

План автора 24.11.2026, не на зараз. Репозиторій стане публічним: його показуватимуть рекрутерам і на технічних співбесідах. Брати після [accessibility-audit.md](accessibility-audit.md).

## Що зробити

- Перекласти документацію українською на англійську: коренева `README.md`, README поруч із кодом, `CLAUDE.md`, коментарі в коді.
- Причесати кореневу `README.md` для стороннього читача: що це за застосунок, знімки екрана, стек, як запустити, як влаштовані тести.
- Технічний план у `docs/` тимчасовий (див. `CLAUDE.md`, «Документація»): перед показом перенести решту знань у код і README поруч, а план прибрати.

## Що вирішити на старті

- Правило мови в `CLAUDE.md` («Українською: документація ... коментарі в коді») зміниться на англійську. Чи лишаються українською описи задач і PR.
- Що робити з `tasks/`: перекласти, лишити українською чи прибрати з публічної версії.
- Що в `CLAUDE.md` і `.claude/` - особисті правила роботи, а що варто показувати.
- Перевірити історію git і PR на те, що не варто публікувати.
