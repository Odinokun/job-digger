# 3.15 Сторінка Jobs з чотирма вкладками

**Етап 3 — Парсинг і вакансії**

Фіксований порядок вкладок: Unread · Read · Favorites · All. За замовчуванням відкривається Unread.

- Unread — активні, ще не прочитані
- Read — активні прочитані
- Favorites — усі з позначкою Favorite, зокрема зниклі з сайту (Closed)
- All — усі активні незалежно від статусу

Для кожної вакансії: назва, компанія, локація, дата виявлення. Фільтрів за компанією, локацією чи типом зайнятості немає. Експорту вакансій немає.

План: docs/ui.md розділ 4.1.

**З рев'ю 1.13:** порожні вкладки мають різний текст — «вакансій ще немає» з кнопкою, що веде в Add company, «усе прочитано» для Unread, «немає обраних» для Favorites. Порядок — від найновішої дати виявлення, по 50 рядків із Load more (модуль із задачі 2.10). Локація необов'язкова: якщо джерело її не дало, у рядку стоїть «—». Дата виявлення — абсолютна за локаллю.
