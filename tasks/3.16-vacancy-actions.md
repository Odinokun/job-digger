# 3.16 Дії над вакансією

**Етап 3 — Парсинг і вакансії**

Перемикач Mark as Read / Mark as unread, Favorite / Remove from Favorites, відкриття оригінальної вакансії в новій вкладці.

Правила: відкриття URL **не** змінює статус Read. Посилання відкриваються з `rel="noopener noreferrer"`, назви й локації показуються як текст, не як HTML. URL приймаються тільки з http/https.

План: docs/ui.md розділ 4.1, docs/security.md розділ 13, пункт 4.

Остання задача на шляху до зеленого 3.20: наприкінці зняти тег `@pending` з `e2e/vacancies.spec.ts` - сценарій стає звичайним і далі йде в CI.
