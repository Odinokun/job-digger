# 7.06 Перенесення даних у Neon

**Етап 7 — Підготовка до Vercel**

Локальні дані переносяться онлайн через `pg_dump` / `pg_restore` разом зі статусами Read і Favorite.

Можливе, бо локально й онлайн — той самий PostgreSQL з однаковою основною версією.

План: docs/overview.md розділ 2.

Після переїзду робочого екземпляра онлайн (нагадування з 6.09-6.10, 20.11.2026):

- у клоні `npm run autostart:off` - локальний сервер більше не потрібен;
- локальні копії (`BACKUP_DIR`) для Neon не працюють - вирішити, як робити копії там;
- **вимкнути доступ терміналу до iCloud Drive** (System Settings → Privacy & Security → Files and Folders): автор видав його 20.11.2026 лише заради копій у `BACKUP_DIR`. Окремий доступ автор видав і процесу автозапуску (вікно macOS при першій копії з `launchd`, 20.11.2026) - прибрати і його.
