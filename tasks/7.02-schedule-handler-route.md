# 7.02 API-маршрут обробника розкладу

**Етап 7 — Підготовка до Vercel**

Легкий обробник, який перевіряє, чи настав час загальної перевірки для кожного користувача, і за потреби запускає її.

Захищений секретним ключем з ENV, щоб сторонні не могли запускати перевірки. Це один із двох винятків із правила «усе лише після входу».

Для API-маршрутів (не Server Actions) перевірка Origin додається вручну.

План: [docs/security.md](https://github.com/Odinokun/job-digger/blob/plan-v1.4.0/docs/security.md) розділ 13 (пункти 2, 6), [docs/checks-and-queue.md](https://github.com/Odinokun/job-digger/blob/plan-v1.4.0/docs/checks-and-queue.md) розділ 8.
