# Рядок вакансії на телефоні

**Поза етапами — інтерфейс** · без строгого TDD (верстка), регресійна перевірка в `e2e/mobile.spec.ts`

Знахідка автора 27.11.2026 (скріншот на 390 px): на телефоні блок «дата + Read + Favorite» стоїть праворуч від короткої назви, а під довгою переноситься вниз і притискається ліворуч. На різних картках він у різних місцях. Причина - `flex-wrap` у рядку: блок переноситься, лише коли не вміщається поруч.

Рішення автора: на телефоні (до `sm`, 640 px) блок завжди під назвою й вирівняний по правому краю картки. Від `sm` - як було, праворуч від назви. Скріншоти в README перезняти.
