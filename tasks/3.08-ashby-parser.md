# 3.08 Парсер Ashby

**Етап 3 — Парсинг і вакансії** · строго TDD

Читання вакансій через публічний API Ashby за спільним інтерфейсом парсера. Збережена реальна відповідь — у фейковому сервері.

План: docs/discovery-and-parsing.md розділ 6.

## Рішення (18.11.2026)

- Межі тестування: `ashbyBoard`, `parseAshbyJobs` (юніт, на збереженій дошці Linear) і `readAshby` (інтеграційні).
- API віддає все одним запитом разом з описами, без сторінок: OpenAI - 14 МБ. Рішення автора: більший ліміт (30 МБ) лише для запитів до API Ashby через `client.get(url, { maxBytes })`, довільні сайти - 5 МБ.
- Знайдено й виправлено баг клієнта: завелика відповідь, що прийшла повністю, давала успіх із порожнім тілом, а не `too-large`.
- `isListed: false` - пропускається, у `skipped` не рахується.
- Справжні дані (порожня назва в OpenAI) змінили правило кривих записів для всіх парсерів - рішення автора: зламана структура валить усю відповідь, вада даних пропускає вакансію й рахується в `skipped` (`collectVacancies`).
