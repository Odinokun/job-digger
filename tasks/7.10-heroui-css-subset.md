# 7.10 Підключати CSS лише тих компонентів HeroUI, які використовуємо

**Етап 7 — Підготовка до Vercel**

`src/app/globals.css` імпортує `@heroui/styles` цілком, тому у збірку потрапляють стилі всіх 73 компонентів бібліотеки. Виміряно під час 2.03: `.next/static/chunks/*.css` важить **462 КБ** нестиснутого, хоча застосунок використовував тоді один компонент — `Card`.

**Що можна зробити:** у пакета є селективні експорти (`package.json`, поле `exports`):

- `@heroui/styles/base` — базовий шар;
- `@heroui/styles/themes/default` — змінні теми;
- `@heroui/styles/components/card.css`, `/button.css` тощо — окремі компоненти;
- `@heroui/styles/utilities`, `/variants`.

Тобто `globals.css` може імпортувати лише потрібне замість усього пакета.

**Рішення 17.11.2026 (розбір колонки Analyze):** робимо в етапі 7, коли список компонентів заморожений. Головне невідоме картки вже посунулося: під час 2.03 в коді був один `Card`, а на середині етапу 2 їх уже вісім — `Toast`, `Button`, `Card`, `Modal`, `TextField`, `Input`, `Label`, `FieldError`. До кінця етапу 6 реалістично 20-25 із 73: виграш лишається, але зробити це раніше означає повертатися до імпортів із кожним новим компонентом.

**Кроки:**

1. Зміряти **стиснутий** (brotli) розмір CSS-чанку — саме ця цифра вирішує, чи варто взагалі. 462 КБ на диску нічого не кажуть про відповідь сервера.
2. Якщо виграш вартий — селективні імпорти плюс спосіб не забути рядок при новому компоненті: забутий імпорт означає компонент без стилів, і помітити це можна лише очима. Чи ловиться це лінтом або тестом?
3. Якщо не вартий — записати відмову з цифрою в README і закрити тему.

Перевірено під час повного імпорту: `@heroui/styles` сам тягне `tailwindcss`, але preflight у збірці не дублюється — при селективному імпорті це треба перевірити ще раз.

Знайдено під час 2.03, коли інтерфейс переводився на токени HeroUI.

## Відмова 21.11.2026

Крок 1 зроблено: продакшн-збірка робочого екземпляра - CSS 484 КБ на диску, **36 КБ brotli** (47 КБ gzip). Використано близько 16 компонентів із 86; селективні імпорти дали б орієнтовно 15-20 КБ стиснутого. Локально виграшу немає, на Vercel - мізерний, а забутий імпорт лишає компонент без стилів без жодного сигналу від лінту чи тестів. Рішення автора: не робимо.
