# 7.08 Перший деплой на Vercel

**Етап 7 — Підготовка до Vercel**

Деплой на тариф Hobby, налаштування ENV у Vercel (`DATABASE_URL` на Neon, секрет обробника, ключі Google, allow-list email), перевірка роботи розкладу й черги онлайн.

Фінальна картка плану.

Усе має лишитися безкоштовним: Vercel — тариф Hobby, Neon — безкоштовний тариф (7.01). Секрети — лише в ENV Vercel, у коді й у git їх немає.
