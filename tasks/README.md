# Задачі

Джерело правди щодо задач проєкту: що треба зробити, що в роботі і що вже готово. Один файл - одна задача (колишня картка Trello). Дошка Trello «JD - Job Digger» лишається архівом і більше не оновлюється. Задачі, завершені до переходу, сюди не перенесені: їхні чеклісти - у Trello, а код і опис - у злитих PR.

## Файл задачі

Назва - `N.MM-slug.md`: номер задачі і коротка суть англійською, як у назві гілки (`2.07-csv-import.md`).

```markdown
---
status: todo
stage: 2
pr:
---

# 2.07 Імпорт CSV

Що робимо і навіщо. Де важливий порядок - «брати перед X.YY».

## Кроки

- [x] Парсер рядка
- [ ] Валідація
```

- `status` - колонка дошки, одне з: `analyze`, `backlog`, `todo`, `in-progress`, `testing`, `done`.
- `stage` - номер етапу з [docs/roadmap.md](../docs/roadmap.md).
- `pr` - номер Pull Request, коли він зʼявиться.

Значення статусів ті самі, що були в колонок Trello: `analyze` - ідеї, ще не продумані; `backlog` - усі задачі з плану; `todo` - взяті в найближчу роботу; `in-progress` - лише одна задача за раз; `testing` - PR відкритий, автор перевіряє; `done` - змерджено.

Статус і чекліст змінюються в тому самому PR, що й код задачі.

## Дошка

Статуси всіх задач:

```sh
grep -H "^status:" tasks/[0-9]*.md
```

Задачі однієї колонки:

```sh
grep -l "^status: todo" tasks/[0-9]*.md
```
