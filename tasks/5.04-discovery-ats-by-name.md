# 5.04 Пошук: ATS за назвою компанії

**Етап 5 — Пошук кар'єрних сторінок**

Третій, найменш надійний спосіб: перевірка ATS за назвою компанії (PeopleForce, Greenhouse, Lever, Workday, Ashby тощо).

Такі знахідки позначаються «знайдено за назвою — перевір» і **ніколи не додаються автоматично**.

Зовнішній пошуковий API у першій версії не використовується: надійних безкоштовних варіантів немає (Google Custom Search API закритий для нових клієнтів і вимикається 1 січня 2027).

План: [docs/discovery-and-parsing.md](https://github.com/Odinokun/job-digger/blob/plan-v1.4.0/docs/discovery-and-parsing.md) розділ 5, [docs/roadmap.md](https://github.com/Odinokun/job-digger/blob/plan-v1.4.0/docs/roadmap.md) розділ 12.

Перевірка «чи є дошка з такою назвою» - читання дошки наявним парсером: на неіснуючу дошку всі чотири платформи відповідають 404 (перевірено 19.11.2026), тобто `not-found`. Заодно відомо, скільки на дошці вакансій - те, що показує пробне читання (5.06). Workday за назвою не вгадується: в адресі є номер кластера й назва сайту (`nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite`).
