# 3.10 Парсер PeopleForce

**Етап 3 — Парсинг і вакансії** · строго TDD

Читання вакансій PeopleForce за спільним інтерфейсом парсера. Платформа поширена серед українських компаній, тому для основного сценарію важлива.

План: [docs/discovery-and-parsing.md](https://github.com/Odinokun/job-digger/blob/plan-v1.4.0/docs/discovery-and-parsing.md) розділи 5 і 6.

## Рішення (18.11.2026)

- Careers API PeopleForce вимагає ключ компанії, тож парсер читає публічну сторінку `/careers` (HTML). Для цього встановлено Cheerio - він у стеку проєкту з самого плану, і він же знадобиться для schema.org (3.11). Install-скриптів у пакета немає.
- Нулю довіряємо лише разом з лічильником «X - Y of N»: карток має бути рівно Y - X + 1, а без лічильника - нуль карток. Інакше `unreadable`.
- `externalId` - числовий ID зі шляху `/careers/v/{ID}-{slug}`.
- Сторінки по 10 за посиланням `rel="next"`, до 5 сторінок.
- Демо-джерело в сіді (`careers.peopleforce.io`) вело на 404 - замінено на `team.peopleforce.io/careers`.
- Деталі - `src/server/parsers/README.md`, «PeopleForce».
