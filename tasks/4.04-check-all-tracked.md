# 4.04 Check all для всіх Tracked

**Етап 4 — Черга та перевірки**

Брати перед 4.12.

Кнопка на вкладці Tracked створює завдання для всіх кар'єрних джерел компаній цієї вкладки. Одне джерело = одне завдання: для 300 джерел створюється 300 завдань.

Не блокує інтерфейс. Нові вакансії з'являються в Unread одразу, щойно перевірено їхнє джерело. Якщо закрити вкладку браузера — перевірка продовжується на сервері.

Компанії з Not tracked **ніколи** не беруть участі в Check all.

План: docs/checks-and-queue.md розділ 8.
