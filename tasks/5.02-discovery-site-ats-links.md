# 5.02 Пошук: посилання з сайту компанії на ATS

**Етап 5 — Пошук кар'єрних сторінок**

Найнадійніший спосіб, тому перший: шукаємо на сайті компанії посилання на ATS (наприклад, кнопка Jobs веде на Greenhouse).

Знахідки цього типу вважаються надійними: саме вони автоматично додаються в Find new pages.

План: docs/discovery-and-parsing.md розділ 5, пункт 3.

Перша задача, якій потрібен сайт компанії на фейковому вебсервері: сторінка `acme.example` для сценарію `e2e/find-pages.spec.ts` (5.12). Вирішити, як фейковий сервер віддає корінь сайту (шлях `/acme.example/` - тека, а не файл), і чи може сторінка сайту бути синтетичною - збережені відповіді досі лише справжні, без правок (`src/server/http/testing/README.md`).

Рішення автора 19.11.2026: сторінки сайтів компаній для тестів пошуку - синтетичні, на зарезервованих доменах `.example`. Справжні відповіді лишаються правилом для платформ.

## Кроки

- [x] `boardUrlOf` - посилання на ATS → адреса дошки (через функції парсерів)
- [ ] `atsLinksOnPage` - посилання й iframe зі сторінки, відносні адреси, дублікати
- [ ] Фейковий сервер віддає корінь сайту; синтетична сторінка `acme.example`
- [ ] `findSiteAtsLinks` - головна сторінка компанії через HTTP-клієнт
