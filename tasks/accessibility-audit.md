## Рішення (автор, 25.11.2026)

- Ціль - [WCAG 2.2](https://www.w3.org/TR/WCAG22/) рівня AA: усі критерії рівнів A і AA ([Understanding Conformance](https://www.w3.org/WAI/WCAG22/Understanding/conformance)).
- Автоматична перевірка - `@axe-core/playwright` у E2E ([документація Playwright](https://playwright.dev/docs/accessibility-testing)), сценарій `e2e/accessibility.spec.ts` на кожному PR. Плюс один прогін Lighthouse для звіту.
- Автоматика ловить лише частину проблем, тому клавіатуру Claude перевіряє через Playwright, а VoiceOver автор проходить руками за чеклістом нижче.
- Дрібні виправлення - кроками в цій задачі, одне правило WCAG на крок. Велика переробка - окрема задача після «ок» автора.
- Результат - короткий розділ «Accessibility» у кореневій `README.md`, деталі - у [src/app/README.md](../src/app/README.md).

- Контраст тексту й іконок в обох темах. Частину вже звіряли для теми Ink ([src/app/README.md](../src/app/README.md#ink-theme)).

- `prefers-reduced-motion` для анімацій.
- Масштаб 200% і телефон.

## Lighthouse: для автора

Chrome DevTools → Lighthouse → Mode «Navigation», Categories лише «Accessibility», Device Desktop. Прогнати `/`, `/companies`, `/history`, `/settings` у робочому екземплярі. Lighthouse використовує той самий рушій axe, тож очікується 100 або зауваження поза тегами WCAG.

Результат (26.11.2026, Lighthouse 13.5, axe-core 4.13): `/companies` - 98, єдине зауваження `heading-order` (best practice, не WCAG): після `h1` одразу `h3` назви картки. Решта сторінок - без зауважень. Виправлено в задачі 6.29 прихованим `h2` над списком; `heading-order` тепер перевіряє й axe у E2E.

## VoiceOver: чекліст для автора

Вмикається `Cmd+F5`, навігація `Ctrl+Option+стрілки`, ротор `Ctrl+Option+U`.

- [ ] Jobs: перемикання Unread / Read / Favorites / All, Mark as read і Undo, Favorites - чи оголошується зміна в рядку.
- [ ] Companies: модалки додавання й редагування, підписи полів, помилки валідації, повернення фокусу після закриття, пошук на вкладці All.
- [ ] Check all і History: чи оголошуються старт, прогрес і завершення перевірки, як читається таблиця History.
- [ ] Settings: перемикачі теми й мови, збереження, чи міняється мова читання після зміни мови інтерфейсу.
