# Аудит інтерфейсу

**Поза етапами — UI/UX** · без коду

Запит автора 21.11.2026: на сайті є невдалі рішення інтерфейсу. Наприклад, у Edit company кнопка Remove скаче, плейсхолдери схожі на значення, текст зливається в одну масу, Cancel і Save здаються різного розміру, а в темній темі вторинна кнопка зливається з фоном. Треба переглянути весь сайт і знайти проблеми такого типу.

Як робили:
- знімки Playwright усіх екранів і діалогів у світлій і темній темі, на 1280 і 390 px, на dev-базі (нічого не збережено);
- заміри: висоти кнопок, кольори токенів, ширина сторінки на телефоні.

Звіт зі скриншотами і пропозиціями: https://claude.ai/artifact/VBtMs2JLVT1bWZzzvHHxwD (приватний, у автора).

Головне:
- на 390 px усі сторінки скроляться вбік (413-484 px);
- вторинні кнопки мають контраст з фоном близько 1.2:1, тому без меж здаються меншими (Cancel і Save насправді обидві 36 px);
- ієрархії тексту майже немає: заголовок діалогу 16/500, підпис поля 14/500, а підзаголовки розділів блідіші за підписи полів;
- плейсхолдери схожі на значення;
- Remove залежить від довжини адреси;
- стан Unsupported червоний у світлій темі і жовтий у темній.

## Рішення автора

- **B1, рядок джерела в картці (21.11.2026):**
  - адреса завжди під рядком стану («Unsupported page», «Own page», платформа), незалежно від довжини;
  - відстань між ними щонайменше вдвічі менша, ніж зараз;
  - адреса в картці в один рядок з «…», повна — у підказці при наведенні;
  - повністю адреса видна лише в Edit company.

- **A1:** телефон без горизонтального скролу; меню-бургер замість скролу меню; E2E-перевірка ширини.
- **A2:** вторинні кнопки з рамкою `--field-border`.
- **A3:** шкала тексту з чотирьох рівнів.
- **A4:** плейсхолдер лише для формату з «e.g.», блідіший.
- **A5:** у Edit company кошик через `IconButton` праворуч, поле підпису з видимим «Label».
- **A6:** червоний лише для помилок, жовтий для «потребує уваги» в обох темах, одна кольорова мітка на картку.
- **B2:** на десктопі дві колонки, кожна картка за висотою вмісту; на телефоні одна колонка. Змінено автором того ж дня після задачі [ui-mobile-layout](ui-mobile-layout.md): одна колонка на будь-якій ширині і контейнер `max-w-5xl` замість `max-w-7xl` - зроблено в [ui-small-screens](ui-small-screens.md).
- **B3:** «Компанія · місто», компанія виділена, точка «нова» всередині колонки.
- **B4:** Save неактивна, доки не заповнені Company name **і Company website**. Сайт стає обов'язковим завжди - це скасовує рішення картки 2.17 (компанія без сайту); окрема задача.
- **B5:** вибір CSV-файлу кнопкою у стилі застосунку з назвою файлу, чіткий неактивний стан.
- **B6:** лише підсвічування рядка при наведенні, ширину не чіпаємо.
- **C1:** очевидніші іконки або текст для «все прочитано» / «непрочитане».
- **C2:** сильніше затемнення під діалогом у темній темі.
