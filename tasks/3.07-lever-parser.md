# 3.07 Парсер Lever

**Етап 3 — Парсинг і вакансії** · строго TDD

Читання вакансій через публічний API Lever за спільним інтерфейсом парсера. Збережена реальна відповідь — у фейковому сервері.

План: docs/discovery-and-parsing.md розділ 6.

## Рішення (18.11.2026)

- Межі тестування: `leverSite`, `parseLeverPostings` (юніт, на збереженій відповіді демо-сайту `leverdemo`) і `readLever` (інтеграційні - фейковий вебсервер і власний сервер зі сторінками).
- Сторінками по 100 через `skip`/`limit`, до 5 сторінок: без `limit` Palantir важить 5,9 МБ і не вміщується в ліміт клієнта 5 МБ. Ліміт сторінок поки параметр `maxPages`; ENV - задача 3.12.
- Збій будь-якої сторінки - збій усього джерела.
- Локація - усі `allLocations` через кому.
- Спільний код запиту JSON винесено в `shared.ts` (`fetchJson`), Greenhouse переведено на нього.
- Регіон ЄС (`jobs.eu.lever.co` → `api.eu.lever.co`) підтримується - документація його описує.
