## Підсумок

Ми отримали специфікацію застосунку, який спочатку працюватиме локально, але не потребуватиме повного перепроєктування для переходу в онлайн.

**Основний принцип:** мінімум зайвого функціоналу в інтерфейсі, але надійна архітектура для сотень компаній, перевірок, помилок і повторного виявлення вакансій.
