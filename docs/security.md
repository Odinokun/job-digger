# Job Digger - Безпека

Частина технічного плану Job Digger v1.4.0. Карта всіх файлів - у [README](README.md).

## 13. Безпека

Правила локальної версії - у [`CLAUDE.md`](../CLAUDE.md#безпека): сервер лише на 127.0.0.1, зміни даних через Server Actions, захист від SSRF ([`src/server/http/README.md`](../src/server/http/README.md)), вміст сайтів лише як текст, CSV-експорт без формул ([`src/server/csv/README.md`](../src/server/csv/README.md)), секрети в ENV.

### Онлайн (етап 7)

1. **Усе - лише після входу.** Виняток - обробник розкладу і перезапуск черги. Вони захищені секретним ключем з ENV, щоб сторонні не могли запускати перевірки.
2. **Секрети - лише в ENV:** ключі Google, `DATABASE_URL`, секрет обробника.
3. **Email зі списку дозволених перевіряється на кожному запиті**, а не лише при вході. Якщо прибрати email з ENV, доступ зникає одразу.
